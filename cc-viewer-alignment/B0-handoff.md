## 补充实时故障复核

在 [冷加载探针](./probes/b0-cold-ingest.mjs) 基础上新增 [实时失败探针](./probes/b0-live-failure.mjs)：

```sh
env -u CXV_BYPASS_PERMISSIONS node cc-viewer-alignment/probes/b0-live-failure.mjs
```

执行当前源码提取的 `_queueV2Commit`/`handleEntryObject`，仅模拟 archive 适配器和入队失败；服务端使用真实 writer、snapshot 注册、`serveLogV2Live` 及 watcher，模拟响应对象的 write 抛错。独立探针进程捕获 unhandledRejection 后清理临时目录及订阅，不修改产品代码。

| 注入 | 实测 | B3 迁移验收 |
| --- | --- | --- |
| archive apply 抛错 | appliedSeq 保持 1，触发一次 reset | 保留已有 reset 保护 |
| handle 内 push 抛错 | 内部 catch 吞错，appliedSeq 变 2，无 reset；重发 seq=2 被跳过 | 入队/提交成功前不确认，失败须重建或可靠恢复；还需验证实际 rAF flush 失败 |
| SSE write 首次抛错、reset 可写 | 两次 write，end 成功，订阅清除，无未处理拒绝 | 保留正常错误关闭路径 |
| SSE write 持续抛错 | 第二次 reset write 也抛错，未调用 end，出现未处理拒绝，订阅仍为 1；探针随后手动 close 清理 | 关闭与资源释放放入不依赖再次写成功的路径；验证背压、关闭竞态与 async activeCheck |

这些是受控异常，不是自然流量复现；退出 0 表示含已知缺陷的观测断言一致。`0670581b3d` 的失败释放属于需适配 B3；首轮刷新数据链路已有实现，`d7f355ba89` 的 response 消费语义仍归 B3/B4，详见 [原始记录](./B0-cold-ingest-review.md)。
